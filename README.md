# Avatar Meeting Agent

A simple web-based tool that displays a looping video avatar for use in video meetings.

## Overview

This project provides a full-screen looping video player designed to serve as a virtual avatar during video conferences. It can be used as a virtual camera source or shared screen to display an animated avatar representation.

## Features

- Full-screen video display with black background
- Seamless video looping
- Autoplay with muted audio
- Responsive design that fits any screen size
- No external dependencies

## Usage

1. Open `index.html` in a web browser
2. The video will automatically start playing in a loop
3. Share the browser window or use it as a virtual camera input in your video conferencing application

## Files

- `index.html` - Main webpage that displays the looping video
- `ympvouico7ehtcxmno20.mp4` - Current avatar video being displayed
- `kling_20251228_Image_to_Video__171_0.mp4` - Alternative avatar video

## Customization

To use a different avatar video, edit `index.html` and change the video source path:

```html
<source src="your-video-file.mp4" type="video/mp4">
```

## Requirements

- A modern web browser with HTML5 video support
- Video files in MP4 format (H.264 codec recommended for best compatibility)
